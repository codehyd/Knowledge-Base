# 功能 15 · 编辑扩展与双链

> 产品：[15-扩展-编辑扩展与双链](../../产品/15-扩展-编辑扩展与双链.md)  
> UI：笔记 TipTap · 知识正文预览

## 1. 目标

- 声明式编辑扩展注册表（首期仅内置）
- `[[` 补全、芯片渲染、点击跳转
- 知识预览可点双链
- 落盘保持字面 `[[…]]`，图谱解析不变

## 2. 技术要点

| 项 | 做法 |
|----|------|
| API | `GET /api/vault/link-targets?q=&limit=` |
| 解析 | 复用 `vault/wikilink.py` |
| 前端注册表 | `apps/web/src/shared/editor-extensions/` |
| 编辑器 | TipTap Wikilink mark + 补全面板 |
| 预览 | PreviewBody 轻量替换 `[[…]]` 为可点链 |

## 3. 验收

- [x] 输入 `[[` 可搜索 vault 笔记并插入
- [x] 保存后图谱仍解析双链（字面量落盘）
- [x] 点击芯片打开目标；断链可辨
- [x] 知识预览双链可点
- [x] `/` → 双链走搜索而非 `prompt`

## 4. 不做（本期）

第三方 JS 插件、Lake 双链、扩展市场、远程补全 API。
