# 功能 10 · 知识对话与检索

> UI：[figma/04-知识对话](../../../figma/04-知识对话.png)  
> 产品：[03-拒答与质量](../../产品/03-拒答与质量.md)

## 1. 功能目标

基于已入库切片做检索增强生成（RAG）：库内问题有据作答并带来源；库外问题拒答（细则见功能 11）。

## 2. 技术流程

```text
用户问题
  → 立刻落库：用户消息 + pending 助手占位（可切页）
  → 后台：embed / 检索 → LLM → 写回助手消息（done / error）
  → 前端轮询会话消息直至无 pending
  → 解析答前可信度标记 trust（ok / suspect / conflict）
```

## 3. 技术要点

| 项 | 做法 |
|----|------|
| 检索 | pgvector `ORDER BY embedding <=> :q LIMIT k` |
| 阈值 | cosine；可设最小相似度阈值（如 0.35，需实测调） |
| 提示词 | 只能依据片段；无依据必须拒答；答前可标库内材料存疑/冲突（非用通识补全） |
| 可信度 | 响应字段 `trust`：`ok` / `suspect` / `conflict`；`trust_note` 简述原因；前端独立样式 |
| 流式 | MVP 可非流式；进阶 SSE |
| 范围 | query `category_id`；中医库空时该过滤下更易拒答（正确行为） |

## 4. 实现步骤

1. `POST /api/chat` `{ message, category_id?, strict? }`
2. 组装 citations：`{ entry_id, title, source, snippet, score }`；以及 `trust` / `trust_note`
3. 前端气泡展示引用 chip；拒答、存疑、冲突用独立样式
4. 会话消息持久化含 trust 字段，历史回看可还原
