# 14 · 扩展：笔记库与 Markdown 编辑器

> **定位**：侧栏独立「笔记」页，类 Obsidian 管理 `data/vault` 多级文件夹；Typora 轻量所见即所得 + `/` 命令栏。  
> **保存**：自动入库并重切片，对话可检索。  
> **二期**：复用编辑器改 Skill 的 `SKILL.md`（见 [13](./13-扩展-Skill安装与市场.md)）。  
> **双链 / 编辑扩展**：见 [15](./15-扩展-编辑扩展与双链.md)。

---

## 1. 产品形态

| 项 | 说明 |
|----|------|
| 入口 | 侧栏 **笔记** → `/notes`（左文件树 + 右编辑区） |
| 物理库 | `data/vault/**/*.md`，可建子文件夹 |
| 我的资源 | 分类 **笔记库**，列出 vault 内笔记；可「打开编辑」 |
| 旧入口 | 知识/喂养「写笔记」跳转 `/notes`；知识详情「在笔记库编辑」会先 import |

## 2. 与空库原则

编辑只改用户自己的 vault 材料；保存后进入检索切片。不引入通识百科。

## 3. 快捷键（节选）

| 操作 | Windows | macOS |
|------|---------|-------|
| 保存入库 | Ctrl+S | Cmd+S |
| 加粗 / 斜体 | Ctrl+B / I | Cmd+B / I |
| 下划线 / 删除线 | Ctrl+U / Ctrl+Shift+X | Cmd+U / Cmd+Shift+X |
| 行内代码 | Ctrl+` | Cmd+` |
| 标题 1–3 | Ctrl+Alt+1..3 | Cmd+Alt+1..3 |
| 列表 / 任务 / 引用 | Ctrl+Shift+8/7/9/B | Cmd+Shift+… |
| 代码块 | Ctrl+Alt+C | Cmd+Alt+C |
| 链接 | Ctrl+K | Cmd+K |
| 插入块 | `/` | `/` |
