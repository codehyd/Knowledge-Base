# 15 · 扩展：编辑扩展与双链

> **定位**：声明式「编辑扩展」贡献点；首发官方内置 **Obsidian 风格双链**。  
> **红线**：第三方包只许清单 + 模板，**不执行任意 JS**（与 [13](./13-扩展-Skill安装与市场.md) 一致）。  
> **前提**：笔记库见 [14](./14-扩展-Markdown编辑器.md)；双链真相在 `.md` vault。

---

## 1. 形态（已定 A）

| | 说明 |
|--|------|
| 扩展 | 本地 / 内置包，用 `extension.json` 声明能力 |
| 首发 | 官方内置 `wikilink`：`[[target]]` / `[[target\|alias]]` |
| 语雀 Lake | **不做**双链主路径；排版实验与 vault 双链分离 |
| 市场 / 远程 API | 后置 |

## 2. 贡献点

| 贡献点 | 含义 | 首期 |
|--------|------|------|
| `slash.items[]` | `/` 菜单项（插入固定 Markdown） | 内置双链；第三方可追加 |
| `marks.wikilink` | 双链识别、芯片样式、点击 | 内置开启 |
| `resolve.vault` | 解析为 vault 笔记并跳转 | 内置 |

包形态（装包 UI 后置，契约先定）：

```text
editor-ext/
  extension.json
  README.md        # 可选
  templates/       # 可选
```

## 3. 用户路径（双链）

```text
笔记中：
  · 输入 [[ 搜索库内笔记（列表不含「当前这篇」整篇，避免无意义自链）
  · 输入 笔记名# 可搜索该笔记内的多级标题，插入 [[笔记#标题]]
  · 或按 Ctrl+Shift+L（Mac：⌘⇧L）打开链接面板（Markdown / 语雀模式通用）
  · 工具栏「链接」按钮同上
  → 保存后图谱解析到「笔记」节点（标题锚点用于跳转，同笔记自链不进图谱边）
  → 点击芯片 → 打开目标笔记；若带 #标题 则滚到对应标题
```

断链：弱样式可辨，不伪造目标。语雀模式插入的是字面 `[[…]]`（落盘 md 可解析）；不在 Lake 内核内做自定义卡片。

同笔记 `[[本篇#某标题]]`：允许（文内跳转）；`[[本篇]]` 整篇自链：补全中隐藏。
