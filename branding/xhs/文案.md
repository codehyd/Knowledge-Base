## 重新生成（实机截图）

1. 启动预览：`cd apps/desktop && npm run dev`（或 web + API）
2. 确保 `http://127.0.0.1:41779` 与 API `18765` 可访问，且库里有示例条目时效果更好
3. 执行：

```bash
cd branding/xhs
npm install   # 首次
npm run generate
```

脚本：`generate.mjs`（Playwright + 本机 Chrome 截图 + 品牌模板合成）

## 文案 A（推荐 · 故事感）

**标题：**
用 Vibecoding 搭了个桌面知识库，求拍砖

**正文：**
最近用 vibecoding 做了一个桌面端项目叫「空库」。

定位很简单：
- 默认是空的，不预装通识百科
- 自己喂电子书 / 笔记 / 视频链接 / 本地音视频
- 视频可自动抽文案（链接或本地上传 + ffmpeg 转写）
- 对话只按库内作答，引用可点回原文高亮
- API Key（DeepSeek 等）自备，存在本机

技术栈：Electron + React + FastAPI + SQLite。
